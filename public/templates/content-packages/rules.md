# Dofus Lite content packages v1

## Deliverable and import
Produce ONE playable ZIP for the selected type, not merely a design document. Use content.json at the ZIP ROOT, with the exact schema below. UTF-8 JSON, no comments, no trailing commas, no unrecognised fields. Use lowercase ASCII keys and semver. Type class has only class; type dungeon has only dungeon. Required design metadata describes roles, synergies/turn loop, at least two weaknesses and practical counterplay.
The user imports the ZIP in Atelier → Importer un ZIP. Images and JSON are saved together locally; no copying files or running commands is required. The original class.json authoring-kit format is not this runtime format. Do not put a parent folder around content.json.
If you can create files, return the actual ZIP and a brief kit/room summary. If you cannot attach files, be honest and provide one complete Python script (stdlib zipfile, json; no downloads) that writes the exact ZIP, including all JSON. Do not claim to have created a file you cannot attach. Never invent a download link.

## Creative freedom and supported scope
Follow the user's theme for names, visual identity, personalities, tactics and spell combinations. You may combine any of the supported effects. All names/descriptions may be French. This version imports one class or one combat room, not a campaign. Choose any listed map; imported geometry/backgrounds are not supported yet. Each creature may have a different reference model, artwork and a unique spell kit. You define EVERY creature's spells; its original reference spellbook is replaced completely.
Custom mechanics available in v1: damage, lifeSteal, heal, buffs (damage/power/stats/PA/PM/range/crit/vitality), armor, resistance buffs/debuffs, dodgeable PA/PM removal, range reduction, push, pull, teleport. New summons, poisons, traps, glyphs, conditional triggers, states, resurrection and scripted mechanics are NOT available in this ZIP version. Do not disguise an unsupported mechanic in a description or an animation ID. Adapt the theme honestly to supported mechanics. Existing UI catalogue spells remain available separately.

## Enforced limits
One class: 1–10 spells, equipped weapon additional; level 200, spell grade 6, no custom starting stat bonuses. baseClass supplies characteristic costs and fallback appearance only; equipment is chosen after import. sex 0=male, 1=female.
One room: 1–8 creature definitions and 1–8 TOTAL placed enemies (sum of members.count ≤8). Each definition has 1–10 spells. Keys are unique per owner. members references every defined creature exactly once, with count for duplicates. No unused definitions. Map placements use that map's existing legal starting zones.
Each creature takes level, HP, stats, resistance, initiative and dodge values from an exact monsterId/grade reference in the catalogue. Tuning: HP and stats 25–150% of reference, PA/PM offsets −2..+2. Effective PA must be 1–20 and PM 0–8. Stats include all six reference stats and are rounded; HP is rounded with minimum 1. Resistances/dodge/initiative are unchanged. Reference ID is for stats and appearance only: original spells and ID-specific mechanics are NOT inherited. A dangerous boss reference stays dangerous; choose a reference appropriate to the intended player/party, not the largest HP available.
Spell cost 1–8 PA. Range min/max integer 0–12, min ≤ max. 1–3 casts/turn; 1–3 casts/target and ≤ casts/turn. Cooldown 0–10 turns, no initial cooldown. Critical: 0 disabled, otherwise denominator 2–100 (1/N); failure: 0 disabled, otherwise denominator 2–1000. No decimal fields. Normal variant 1–4 effects. Critical variant is a COMPLETE replacement list, not an addition: 1–4 effects if enabled, [] otherwise. Each variant independently respects every limit.
Balance budget v1: at most 100 points per spell, and 650 points for the complete 1–10 spell kit, including synergies. These SAME gates apply to UI creation, ZIP import and combat. The limits below are structural maxima, never permission to combine all maximum values. Previously saved over-budget creations remain editable, but cannot enter combat until repaired.
Critical variants must have the same effect count/order/kinds, elements, stat, zone and recipients as normal; each critical min/max/duration must be >= the corresponding normal value. The editor keeps an unmodified critical copy synchronized and offers explicit alignment for older definitions. Native catalogue spells keep their original critical mechanics.
Score formula for supported authored spells (no rounding until final ceiling): value V=.325*min+.675*max; duration D=1+.5*max(0,min(8,duration)-1). Direct damage U=V+8 (fixed damage per line), lifeSteal U=(V+8)*1.45; healing U=(V+5)*.9. Push U=5*V, pull U=3.5*V; teleport U=12+4*min(12,rangeMax). Other supported effects use U=V*weight*D; weights: {"buffDamage":0.4,"buffPower":0.1,"buffStat":0.08,"buffPa":15,"buffPm":9,"buffRange":6,"buffCrit":1.5,"buffVitality":0.06,"armor":1.8,"resistBuff":0.45,"resistAllBuff":1.6,"resistDebuff":0.65,"removePa":12,"removePm":9,"debuffPa":15,"debuffPm":11,"debuffRange":6,"debuffStat":0.08,"stealStat":0.13,"stealPa":23,"stealPm":16}. Wisdom stat boost multiplies U by 1.25.
Stacking: buff*, armor and resist* multiply U by 1+.2*max(0,S-1), where S=ceil((duration+1)/max(1,cooldown))*(cooldown>1?1:maxPerTurn). This prices persistent cumulative effects. Any buffPa additionally requires the SUM of PA gain maxima < AP cost, maxPerTurn=1 and cooldown>every PA-effect duration, in both variants. Splitting effects cannot bypass this rule.
Area factor A=1 for self or point. Otherwise radius r=zone letter index (a=0,b=1,c=2); diamond C: A=1.8+.3*r; cross X: A=1.55+.2*r; line L/staff T: A=1.5+.12*r. An enemies-only area multiplies A by 1.12. This is an estimated multi-target opportunity, not the actual in-combat damage coefficient.
Reach factor R=1 for self effects/self casts; otherwise R=(.85+.025*min(12,rangeMax))*(needsLos?1:1.18)*(adjustableRange?1.12:1)*(lineOnly?.9:1)*(rangeMin>=3?.9:1). Each effect contributes U*A*R. A self damage/power/stat boost before a damage line also increases that line's units: multiply by 1+((power+matchingStat)/100*V+flatDamage)/(7*(V+8)), accumulating only preceding caster boosts. Each bonus's own U still counts.
For each variant, Q=7*sum(effect units)/PA/C*L. C=1+.25*min(4,max(0,cooldown-1)); cooldown credit is capped at 2 to prevent extreme burst. L=1 for cooldown>1; otherwise .9 for maxPerTurn=1, or .95 for maxPerTarget=1 if EVERY effect in BOTH variants is point, otherwise 1. Area per-target caps do not reduce score: empty-cell aiming bypasses per-victim limits. Let N=normal Q and K=critical Q (or N when disabled): spell score=ceil(max(N,(N+K)/2,K/1.35)). Base crit denominator and failure chance never discount this envelope: critical gear may reach 1/2.
Kit budget = sum(spell scores)+synergy+rotation. For each amplification kind take the largest SUM of max values in one variant of each spell, then add across spells. Amplification B=total buffDamage/60+(total buffPower+buffStat)/400+total buffPa/4+total resistDebuff/40. Synergy=ceil(max(60,highest offensive spell score)*min(2,B)*.2)+10*max(0,total buffPa-2)^2. The 60-point floor represents the equipped weapon, even without attack spells; the quadratic PA surcharge prevents several individually legal PA generators from creating excessive combined resources. Rotation=10*max(0,number of offensive spells with cooldown>=2 AND score>=75 minus 1). Independent cooldowns and boosters are not free additions.
Original class/common catalogue spells with EXACT unmodified mechanical definitions have their score capped at 100, spending the entire slot budget for exceptional originals. Native-specific limitations remain attached; this exception never applies to new authored spells, altered copies or monster spells. Original class kits in normal gameplay are unchanged. The baseline audit covers all 264 grade-six class entries; unusual native mechanics have estimated utility equivalents, not certified DPS or win-rate rankings. Scores are conservative design gates, not proof of fair PvP matchups.


## Equipment restrictions and class design
Equipment budget v2: 100 points per custom item and 1650 points per outfit containing any custom item. These are SEPARATE from the spell and spellbook budgets: unused equipment points cannot buy stronger spells, and unused spell points cannot buy stronger equipment. Dofus are excluded from the item census, creator, outfit score and AP/MP/range surcharges; their combat bonuses still apply. Keep Dofus equal between comparison builds or omit them from both.

### Required level and calibration
The maximum item score stays 100 at every level. Higher REQUIRED ITEM LEVEL unlocks a larger raw power allowance, so the same permanent bonuses usually cost fewer points at higher levels. This progression follows native data and can plateau; it is not a linear level multiplier. Required item level, not the wearer's level, controls admission of each custom item. Wearing it on a level-200 class does not make a level-50 item eligible for level-200 bonuses. Weapons also have a level-dependent flat-damage reference scenario, so their score is not a simple fixed ratio across levels.
Compare only the same family. For level L, use native references between L-30 and L; if there are fewer than 12, use all that family's references at or below L. Raw total/passive/attack allowances are the 90th percentile of positive values, at least 1 and at least their previous-level allowance. Per-stat ceilings are the 95th percentile of positive stat lines, rounded UP and never lower than at the previous level. Quantiles use linear interpolation. Pets, mounts and shields use their whole family, independently of required level; a mount still requires level 60. Ordinary creations allow at most +1 AP and +1 MP each, only if the other budget checks pass. Missing/zero stat ceilings mean the bonus is unavailable in that family at that level.
Calibration: 6476 non-Dofus entries audited; 1917 distinct ordinary combat references retained. Ethereal weapons, tools, reserved/admin items and unsupported/class-specific effects are excluded from calibration. Utility-only items can still provide numerical utility caps. Use best natural rolls; trained pets contribute one legal specialization, not every alternative added together. Mount bonuses use mount level 100. Native outliers are comparisons, not permission to copy all their strongest bonuses. The downloadable specification contains exact unrounded family/level allowances and stat ceilings; the prompt lists level-200 allowances because imported classes currently start at level 200.

### Permanent bonuses and weapon score
Each positive stat contributes value*weight; the exact allowed stat keys, weights and negative-bonus support are listed below. Pods and prospecting have zero combat weight but still have numerical caps. PvP resistance remains PvP-only. Maluses, equip conditions, set membership, two-handed use and critical failures earn NO discount. Add 40 raw passive points when one item grants both AP and MP, plus 100 for each AP above its first and 90 for each MP above its first.
For weapons, at item level L set F=(10+.15*L)/(1+(100+2*L)/100). Each damage/heal line contributes (mean(min,max)+F), multiplied by 1.5 for lifeSteal and by 1 otherwise. Each AP removal/steal line contributes mean(min,max)*24 instead. For the critical scenario add critBonus to EVERY damage, lifeSteal and heal line before its multiplier when criticals are enabled. Let N and K be the summed normal/critical values. Raw attack power = max(N,(N+K)/2)/AP * area * reach *16, where area=1.35 for hammer/staff zone Xb/Tb and 1 otherwise, reach=1+.035*max(0,rangeMax-1). Critical denominator does not discount this 1/2-critical gear scenario; critical failures do not discount it either.
Raw total = passive+attack. Item score = 100*max(rawTotal/totalAllowance, passive/passiveAllowance, attack/attackAllowance), with the attack ratio zero for non-weapons. Every positive stat must ALSO fit its independent numerical cap; a legal +1 AP is not automatically a 100-point item. Check the unrounded score against 100; the displayed decimal is not extra budget. Negative stats require a supported negative effect and magnitude <=max(1,the positive stat ceiling), with no budget credit.

### Equipment creator limits
Supported families: hats, capes/bags, amulets, rings, belts, boots, bows, wands, staves, daggers, swords, hammers, shovels, axes, shields, pets and mounts. Name 1-80 characters; required level 1-200; supported integer bonuses and fixed permanent rolls. Dofus, special tools, arbitrary effects/scripts and custom set bonuses cannot be created. Appearance comes from a native model; its type, weapon area, handedness and failure rate cannot be overridden. Shields retain their model's rank conditions. Mounted animations are not added by the creator.
Weapon: 2-7 AP; 1-4 lines; melee range exactly 1-1, bows/wands min/max 1-10 with min<=max. Damage/lifeSteal/heal bounds 1-80 per line, AP removal/steal 1-2, min<=max. Critical disabled (0) or denominator 20-100, bonus 0-20 per eligible line. These are structural ceilings, not allowances to set every field to its maximum. Permanent bonus caps AND all power budgets must still pass. Custom gear has fixed rolls and cannot be forgemaged; edit it in the equipment workshop. Saved revisions keep existing equipped copies/replays intact.

### Whole-outfit budget
The 1650-point ceiling accommodates an optimized level-200 native outfit with maximum natural rolls and legal forgemaging/exos scoring 1606.5 (884.3 from items, 22.2 from sets, 700 from AP stacking), with a small margin. This is an outfit allowance; it does not raise the 100-point ceiling or numerical stat caps for any newly created item. Native forgemaging remains subject to its own rules, and custom gear still has fixed rolls.
Count every occupied non-Dofus slot, including both rings, with only one pet OR mount. At character level P, evaluate each item's raw COMBINED power and total allowance at max(P,itemRequiredLevel), and contribute min(100,100*rawTotal/totalAllowance). Each custom item must separately pass its own required-level checks. Add the active set tier's raw permanent power once, normalized as 100*setRawPower/mean(equipped total allowances). Add 175 points per equipment AP above 3, 175 per equipment MP above 2, and 15 per range above 5. Include set stats in these totals; exclude Dofus, base character AP/MP and temporary spell boosts. Round the final outfit score to one decimal as the runtime does.
An outfit with any custom item must score <=1650. All-native outfits retain their existing admission rules; their score is informational. Native level, slot, weapon/shield compatibility and equip conditions still apply. Class-specific set spell modifiers are not fully priced, so passing the score does not establish competitive balance.

### How equipment is delivered today
The class/dungeon ZIP format v1 DOES NOT import equipment, equipped loadouts or equipment artwork. Do not add equipment, customEquipment, loadout or item JSON files to content.json or the ZIP. Create equipment in Atelier → Mes équipements or Stuff → Créer un équipement, then equip it after importing the class. If equipment is part of the theme, supply its design and budget calculations OUTSIDE the importable ZIP. The equipment rules here guide that design and class playtesting; they do not extend the JSON schema.
Test each class with equal-level, comparable-budget gear: baseline stats, high flat damage with multi-line spells/weapons, critical gear approaching 1/2, AP/MP breakpoints, range, resistances and sustain. Boosts apply immediately and may amplify the equipped weapon even in a spellbook without direct attacks. Passing the spell, item and outfit gates separately is necessary but does not prove their combined combat balance.


## Targeting and effects
targetMode enemy: occupied enemy cell and rangeMin≥1. fighter: an occupied cell (ally or enemy; effect target filters recipients). cell: any legal target cell, including empty, useful for zones. freeCell: unoccupied cell. self: rangeMin=rangeMax=0. Only self may have rangeMax=0. needsLos/lineOnly/adjustableRange are booleans; make constraints meaningful.
Every effect has kind,min,max,duration,zone,target. target self affects caster, ally includes caster and allies, otherAlly excludes caster, enemy excludes allies, fighter affects all (friendly fire). Self effects MUST use Pa, regardless of aim point. Other effects apply their zone around the selected cell. A self-cast point effect cannot target enemy/otherAlly. An enemy-cast point effect can target enemy, fighter or self only. A freeCell point effect can only target self, because the destination is empty. Do not use targetMode fighter to promise ally-only legal targeting: PA can be spent on an enemy and its ally-filtered effects then do nothing.
Optional element required ONLY for damage/lifeSteal/resistBuff/resistDebuff: neutre,terre,feu,eau,air. Optional stat required ONLY for buffStat: force,intelligence,chance,agilite,sagesse. Remove irrelevant element/stat fields. Values min/max are inclusive integers, min≤max; positive except teleport which requires both 0. Duration 0–5 for timed effects; 0 for instant damage/heal/movement. Duration 0 means current turn for a buff; enemy PA/PM removal still affects their next turn. Timed bonuses apply immediately.
push/pull require min=max=fixed distance 1–6, target not self, targetMode not self. teleport is the only effect in BOTH variants, targetMode freeCell, effect target self, Pa, min=max=0, duration=0, adjustableRange=false; rangeMax is travel distance. Healing targets self/ally/otherAlly only.
Zone codes: Pa one cell; Cb/Cc Manhattan diamond radius 1/2; Xb/Xc cross radius 1/2; Lb/Lc oriented line 2/3 cells; Tb perpendicular staff shape of 3 cells. Orientation comes from caster to aim point. Direct spell area damage uses 110% at aim cell, then 100%,90% by distance. Weapons have their own Retro rules.

## Balance design, not just validity
Use one clear primary role, optionally one secondary role, usually 1–2 damage elements, a short repeatable turn plan and explicit tradeoffs. A 6–10 spell class should have complementary tools, not ten stronger variants of the same nuke. A creature usually needs 2–5 spells, a boss 4–8. Ten is a limit, not a target. Give bosses pressure and exploitable weaknesses. Avoid eight healers/buffers multiplying one another, permanent locks, unavoidable long-range bursts and multi-hit attacks that scale excessively with flat damage.
Compare each new spell with at least two actual grade-six class spells in the baseline below, matching PA cost, range, area, line of sight, cooldown and targeting. Typical starting raw MEAN damage/PA: ≤6 at range, ≤8 in melee (rangeMax≤2), ≤5 in an area. Use the baseline to tune, never treat maxima as entitlements. Reduce damage for lifesteal, flexible range, enemy-only areas, healing/control on the same cast, or synergy with boosts. Duration, uptime, AP economy, safe range and team support matter as much as a single hit.
Combat scaling: floor(raw roll × (100 + element stat + power)/100 + flat damage), then zone/resistances/armor/other engine rules. Neutral/earth use force, fire intelligence, water chance, air agility. Flat damage applies to EACH line. LifeSteal heals half the actual HP removed. Heal scales with intelligence and healing bonuses. Armor scales with recipient characteristics. PA/PM removal can be dodged. Crit chance improves with agility/crit bonuses. Overkill and healing caps limit actual HP changes. Include these when estimating turns; no made-up displayed damage values.
Test normal/critical variants, boosts→attack in same turn, three consecutive turns, cooldown downtime, obstacles, allies in area, resistance, low/high stats and flat-damage builds. For a dungeon test the entire team, focus fire, control chains, healing and movement on its chosen map. Compare against several original classes at equal level/stuff and multiple seeds. Specify intended player level/party/stuff and target difficulty in description/design. Report what was actually simulated; technical acceptance alone is NOT proof of balance. The game provides manual play and Tester avec l’IA after import.
