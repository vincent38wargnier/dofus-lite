Jouer, sans préparer une équipe

  1. Dans le jeu : Atelier → Importer un ZIP.
  2. Sélectionnez winterfell-last-stand.zip, puis Jouer l’aventure.
  3. Placez les six héros et cliquez sur Prêt. Vous pouvez aussi choisir Regarder l’IA.

Utilisez + / − ou la molette pour zoomer. Glissez le terrain pour déplacer la vue ; sur mobile, pincez avec deux doigts. Ajuster montre toute la carte et le réticule recentre le personnage actif.

La bibliothèque Sorts du combat décrit chaque combattant. L’icône ⓘ d’un sort ouvre sa fiche après une seconde de survol.

Pour modifier cette aventure

Télécharger l’édition créateur : la salle, les six classes et les 48 équipements dans les bibliothèques de l’Atelier. Les budgets de sorts et d’équipements restent appliqués.
