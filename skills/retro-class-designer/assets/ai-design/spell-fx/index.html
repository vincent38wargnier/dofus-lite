Sources de design, pas encore importables en combat. Ce lecteur fonctionne hors ligne. Gardez les fichiers d’effets hors du ZIP jouable ; le jeu utilise toujours son animation visualSpellId.

Sélectionnez ensemble effect.json et les PNG de votre effet. Aucun fichier n’est envoyé sur un serveur.

Le lecteur ajuste le trajet, pas les règles du combat. Vérifiez les quatre directions et les deux distances. La lecture reste en pause si la préférence « Réduire les animations » est activée.
